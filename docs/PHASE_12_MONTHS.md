# 12 months — three people, EOI first

Month 0–3 (you alone)
- Freeze ontology (this pack).
- Four simulated assets on one dashboard.
- Command → Event path with an operator name.
- Security stub: login + audit.
- Record a 5-minute demo video.

Month 3–6 (two join)
- Person 2: adapters (MAVLink / ROS2 / MQTT) and comms TLS.
- Person 3: dashboard polish + alerts on the map.
- You: missions that task UAV and UGV together.
- First hybrid run if hardware exists; else stay on sim and say so honestly.

Month 6–9
- Fusion: detections → tracks → alerts.
- Zone object if the demo needs a keep-out.
- Design document + admin/user manual drafts.
- Reliability: reconnect, stale tracks, battery alerts.

Month 9–12
- Freeze features.
- Test report against EOI §10.
- Hardware kit list (EOI §8).
- Rehearse the acceptance demo until it is boring.
- Handover bundle: source, docs, adapters, recording.

Hiring rule: the two joiners do not start a new UI or a new object model.
